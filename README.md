## Deploy on Vercel
1. Extract this ZIP.
2. Upload the extracted folder to a GitHub repository, or use Vercel's project import flow.
3. Import the repository into Vercel. This is a static HTML site; no build command is required and the output directory is the project root.
4. After deployment, test every page and link on desktop and mobile.
5. Add your custom domain in Vercel if you own one.
6. Replace `https://YOUR-DOMAIN.example/` in `sitemap.xml` with the actual domain, and add canonical URL metadata to each page once the domain is final.

## SEO notes
Metadata, Open Graph tags, descriptive titles, JSON-LD business schema, semantic page structure and responsive layouts are included. Search indexing is not immediate or guaranteed. The sitemap domain must be updated after the live domain is known. `aarohan-learning-demo.html` uses `noindex` because it is a fictional concept page; remove that only if you intentionally want search engines indexing the demo page.
